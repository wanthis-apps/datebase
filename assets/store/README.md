# Google Play 提出用画像

アイコンとフィーチャーグラフィックはピンの図案です。画像の中に旧アプリ名は入っていません。

スクリーンショット4枚は、架空店のデモデータで撮った画面です。審査提出の前に、本番の実在スポットが見える画面へ撮り直してください。

| ファイル | サイズ | 形式 | 用途 |
| --- | --- | --- | --- |
| `icon-512.png` | 512×512 px | PNG。1MB 以内。アルファチャンネルなし | Play Console の高解像度アイコン |
| `feature-graphic.png` | 1024×500 px | PNG。1MB 以内。透過なし | フィーチャー グラフィック |
| `screenshots/` | トリミング後 1080×2106 | JPEG。透過なし。4 枚 | スマートフォンの縦スクリーンショット |

アプリ内の `assets/icon.png`（1024×1024）はランチャーアイコン用で、Play Console の 512×512 アイコンとは別ファイルです。
