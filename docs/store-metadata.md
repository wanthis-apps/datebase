# DateSpot - ストア掲載メタデータ

## アプリ名 (30文字以内)
DateSpot - 失敗しないデートのお店探し

## 簡単な説明 (80文字以内)
「デートで使えるお店」だけを厳選。マップとリストで理想のスポットがすぐに見つかる、デート特化型検索アプリ。

## 詳細な説明 (4000文字以内)
「DateSpot」は、網羅的なレストラン検索ではなく「雰囲気の良いデートスポット」に特化して探せる検索・保存アプリです。

【こんな課題を解決します】
・「結局どこに行けばいいかわからない」とデートの行き先で迷う
・せっかく調べたのに、いざ行ってみたら雰囲気がデート向けじゃなかった
・インスタで見つけた場所をマップ上で整理しておきたい

【DateSpotの強み】
✨ デート向けスポットに特化
雰囲気が良く、デートに最適な場所だけを探せるため、お店選びの失敗を防ぎます。

🗺️ マップ＆リストのシームレスな切り替え
スワイプやタップで、地図上の位置関係と店舗詳細（リスト）を瞬時に行き来できます。

❤️ サクサク動くお気に入り機能
行きたい場所をワンタップで保存。通信を待たずに即座に画面に反映される「楽観的UI」を採用し、ストレスフリーな操作感を実現しました。

【WANTHISについて】
「Wanted This（まさにこれが欲しかった！）」を日常に届けるアプリスタジオです。

## データセーフティ（Data Safety）回答用シート

Play Console の「データセーフティ」用。回答の範囲はプライバシーポリシー（`https://datespot.wanthis-apps.com/privacy`）に合わせる。個人情報の販売、および広告のためのアプリ横断トラッキングはしない。

### 収集するデータ

1. **おおよその位置情報 / 正確な位置情報**
   - 目的: アプリの機能（近くのスポット検索・マップ表示）
   - 共有: 外部第三者との共有なし
   - 処理: 暗号化通信（HTTPS）
   - 取得タイミング: アプリ使用中のみ（`ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION`）。画面を閉じたあとの取得や常時追跡はしない。許可しなくても一覧と詳細は閲覧できる
   - 地図: 表示に必要な範囲で、表示領域の情報が Google の地図サービスへ送られる。広告配信やデータ販売のための提供ではない。フォームがサービスプロバイダへの送信を尋ねる場合は、この委託を申告する
2. **ユーザーID / メールアドレス**（Supabase Auth 利用時）
   - 目的: アカウント管理・お気に入りデータの同期
   - 共有: 共有なし
   - 処理: 認証と保存は Supabase への委託。通信は HTTPS。パスワードは平文で預からない。ゲスト利用では、メールアドレスのない匿名の識別子を発行する場合がある
3. **ユーザーによる操作内容**（お気に入り保存履歴）
   - 目的: アプリ機能の提供
   - 内容: 保存したスポットの識別子と保存日時。アカウントに紐づけ、お気に入りの表示と端末を替えたあとの復元に使う
   - 共有: 共有なし

申告しないもの: 広告識別子、追跡用の端末固有 ID。

## スクリーンショット撮影ガイド

撮影用の架空スポットは `supabase/seed_store_demo.sql` にある。カフェ、夜景、公園（activity）、レストラン（lunch / dinner）、バーを、芝公園から台場にかけて 8 件置いている。画像は Unsplash License の URL。店名と説明は実在の店舗ではない。

### データの入れ方

1. Supabase の SQL Editor で `supabase/seed_store_demo.sql` を実行する。既存の `seed.sql` は削除しない。同じ id なら再実行で上書きされる。
2. アプリを再読み込みし、ホームに「Luminous Cafe & Lounge」などが出ることを確認する。
3. 既存スポットとピンが混ざるときは、エリアを「芝公園」「台場」「汐留」「浜離宮」「竹芝」「六本木」に絞る。
4. 画面は昼テーマ（背景 `#FFF8F6`）にする。ステータスバーやデバッグ表示は入れない。

### 撮影手順

保存先は `assets/store/raw_screenshots/`。撮影後に `npm run crop:screenshots` を実行し、`assets/store/screenshots/` へ同名で出す。

1. **マップ**  
   マップタブを開き、芝公園から台場までピンが複数見える縮尺にする。「Luminous Cafe & Lounge」か「ベイサイド・オーシャンビューテラス」のピンを選んだ状態で撮る。
2. **詳細**  
   ピンまたは一覧カードから「Luminous Cafe & Lounge」を開く。写真、説明文、お気に入りのハートが同時に見える位置で撮る。提携バッジが出る店（ルミエール食堂、ソラノ屋上カフェ）も 1 枚あるとよい。
3. **検索**  
   ホームの検索に `Luminous` または `テラス` と入れる。結果の写真と店名が欠けずに見える状態で撮る。`テラス` は複数件、`Luminous` は 1 件になる。
4. **お気に入り**  
   詳細またはカードのハートを 2〜3 件（例: Luminous Cafe、ベイサイド・オーシャンビューテラス、ルミエール食堂）押してから、お気に入りタブを撮る。お気に入りはログイン中のユーザーに紐づくため、SQL では投入しない。
